## Fixes recentes (já aplicados no arquivo atual)
- **v2.4.1 — crash ao abrir o painel do lápis (fix loop infinito)**: abrir o painel congelava a página. Causa: `tick()` (disparado pelo MutationObserver a cada mudança no body) chamava `atualizarHub()`, que chamava `atualizarPainelTeclas()` e **reescrevia o `innerHTML` de `#waly-teclas-lista` a cada tick**; a reescrita gerava nova mutação → `tick()` → reescrita → ... loop infinito. Fix: guard de igualdade em `atualizarPainelTeclas()` — `if (lista.innerHTML === html) return;` só reescreve quando o conteúdo muda de fato, quebrando o ciclo. `node --check` OK.
- **v2.4.1 — mudança de idioma quebrava o script (fix)**: ao trocar o idioma no app, os `aria-label` dos botões do header mudam (ex.: `Finalizar`→`Finish`, `Fechar conversa`→`Close chat`). O `limparHeaderAcoes()` só reconhecia os rótulos em pt-BR, então passava a esconder **tudo** do grupo de ações — inclusive o lápis e o relógio do próprio script (que não casavam com nenhum padrão e iam para `display:none`). Fix: (a) qualquer botão com `data-walytech`/`data-walytech-rgb`/`data-walytech-timer` **nunca** é escondido; (b) reconhecimento dos nativos ampliado com regex multilingue (`finali[sz]|finish|terminar`, `transfer`, `fechar conversa|close \w*convers(ation|e)|encerrar|cerrar`). `node --check` OK.
- **v2.4.1 — botão do modo preso em "Escuro" (fix)**: o usuário relatou que na aba Modo o botão Escuro ficava sempre marcado como selecionado, mesmo alternando para o modo claro. Causa: `modoApp()` lia apenas a classe `dark` (`html.dark`/`html.light`/`data-theme`) — mas o toggle nativo é um **Radix Switch** controlado por props (`Fpt` no bundle: `checked={e==='dark'}`), e o app pode manter a classe do `<html>` dessincronizada do estado real do tema. Fix: `modoApp()` agora usa como fonte primária o `data-state` do próprio `button[aria-label="Toggle theme"]` (`checked`=dark, `unchecked`=light), com fallback para `html.dark`/`.light`/`data-theme`. Além disso, `atualizarHub()` voltou a ser chamado no topo do `tick()` para a marcação sempre acompanhar o tema mesmo quando alternado fora do hub. `node --check` OK.
